# 0.1.2 — 2026-10-25

## Changed

- **`ukparl_get_committee`** retrieves written submissions and oral sessions through `evidence` and `evidence_detail`, preserving typed metadata, witnesses, relationships and document links ([#5](https://github.com/cyanheads/uk-parliament-mcp-server/issues/5)).
- **`ukparl_search_divisions`** returns the selected member's recorded lobby and teller flag when `memberId` is supplied ([#7](https://github.com/cyanheads/uk-parliament-mcp-server/issues/7)).
- **`ukparl_search_bills`** accepts department, originating House, status and official ordering filters ([#8](https://github.com/cyanheads/uk-parliament-mcp-server/issues/8)).
- **`ukparl_get_bill`** filters amendment collections by published number, decision and sponsoring member ([#9](https://github.com/cyanheads/uk-parliament-mcp-server/issues/9)).
- **`ukparl_get_committee`** filters committee status, open business, evidence acceptance and publication types/dates, with official ordering and cross-committee business discovery ([#10](https://github.com/cyanheads/uk-parliament-mcp-server/issues/10)).
- **`ukparl_search_questions`** searches exact UINs and answering members; undated UINs retain candidates across sessions ([#11](https://github.com/cyanheads/uk-parliament-mcp-server/issues/11)).
- **Lossless delivery** renders reversible JSON blocks with clickable links, optional inline child JSON and adaptive fragments within the existing 24,000-byte envelope ([#14](https://github.com/cyanheads/uk-parliament-mcp-server/issues/14)).
- **Selector errors** identify missing or incompatible fields and concrete repairs while retaining existing error reasons ([#15](https://github.com/cyanheads/uk-parliament-mcp-server/issues/15)).
- **Install metadata and documentation** include the hosted endpoint, Agent Plugins manifests and revised setup guidance.

## Fixed

- **Bill overview handoff** explains that publications remain unchecked instead of claiming no statute link exists ([#6](https://github.com/cyanheads/uk-parliament-mcp-server/issues/6)).
- **Desktop bundles** retain MCP SDK runtime skills modules while removing package-root agent documentation, build-only files and node-gyp intermediates.
