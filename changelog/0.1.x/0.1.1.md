# 0.1.1 — 2026-10-25

## Added

- **Reference lookup** resolves bill stages, bill types, parties, departments, and answering bodies, with identifier and historical coverage guidance.
- **Bill search and detail** retrieve summaries, stages, publications, amendments, and ping-pong motions, with statute links only where the source supplies them.
- **Member search and detail** cover current and former MPs and peers, dated membership searches, profiles, roles, committee seats, official contacts, interests, and recorded voting history.
- **House-scoped divisions** support search, detail, voters, and party totals, preserving teller facts separately from headline counts.
- **Spoken Hansard** returns full contribution text where supplied and preserves historical coverage uncertainty and source speaker sentinels.
- **Written questions** support filtered previews and complete question/answer details, corrections, and attachment links.
- **Committees** expose discovery, membership, business, and publication metadata with source relationships and document links.
- **Source provenance and continuation** retain request URLs, retrieval timestamps, licence notices, whole-record pages, and lossless continuations for large records on both MCP output surfaces.
- **Distribution** includes stdio and Streamable HTTP, scoped npm installation, Claude Desktop bundles, Claude Code and Codex plugins, and multi-architecture containers.
